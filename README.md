# AI Weather Assistant

A Flask web app for viewing temperatures and current conditions in different locations, then asking weather questions with Groq.

## Setup

1. Create and activate a virtual environment.
2. Run `pip install -r requirements.txt`.
3. Add `OPENWEATHER_API_KEY` and `GROQ_API_KEY` to `.env`.
4. Run `python app.py`, then open `http://127.0.0.1:5000`.

Get an OpenWeather key from [OpenWeather](https://openweathermap.org/api) and a Groq key from [Groq Console](https://console.groq.com/keys).
